## 1. 4요소

- **트리거**: 사용자 요청 1회 시작, 수렴까지 반복
- **실행 단위**: 게이트 스위트 실행 → 실패 항목만 수정 → 재실행
- **검증자**: ① `npm run build` ② `npm run lint` ③ `npm test` ④ `node scripts/validateSkills.mjs` — 전부 종료 코드 판정(자기평가 없음)
- **종료 규칙**: 4종 전부 exit 0 (Stop 훅 verifierGate로 기계 강제)

## 2. 안전장치

- 최대 반복 10회 · 토큰 예산 400,000(초과 시 자동 중단·보고) · 같은 실패 시그니처 3연속 시 막힘 중단
- config: `.claude/hooks/verifierGate.config.json` (명세와 일치)

## 3. 범위 밖

- 브라우저 실동작·시각 게이트 — 종료 코드화 불가. 루프 수렴 후 1회 스윕·보고로 별도 수행(LLM 판정을 종료 규칙으로 쓰지 않음)

## 5. 종료 보고

- **수렴: 1회차에 4/4 게이트 통과** (예산 사용: 반복 1/10, 막힘 없음)
- 범위 밖(브라우저 스윕)은 골 1~3 작업 중 각 항목별로 이미 수행됨 — 카탈로그 검색·사용 예시 복사, 토스트 스택, 줌 확대/복귀, 시트 스냅, 캐러셀 자동재생 실동작 확인, 콘솔 에러 0
- 검증자 게이트(Stop 훅)는 사용자 승인으로 **상시 유지** — 이후 모든 세션의 턴 종료마다 4종 게이트가 기계 강제된다
- 상시 게이트 강제 수단: `.claude/hooks/verifierGate.mjs` + `verifierGate.config.json`, `scripts/validateSkills.mjs`(구조 게이트의 정식 스크립트 승격)
