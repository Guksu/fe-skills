## 1. 개요

영어 README에 이어 데모 사이트도 영어로 볼 수 있게 했다. 사용자 문답으로 범위를 "뼈대 + 스킬 목록"으로 정했다. 각 데모 안의 조절 라벨·안내문·국수집 콘텐츠는 한국어 그대로다(52개 파일, 문구 약 500개를 두 언어로 관리하는 비용을 피함). 전환 방식은 화면 안 토글 + 기억.

## 2. 작업내용

- `demo/src/i18n.ts` — `resolveInitialLang`(순서: URL `?lang=` → 저장된 선택 → 브라우저 언어가 한국어면 ko, 아니면 en), `useLang` 훅(선택을 localStorage에 기억, `<html lang>` 반영), 뼈대 문구 사전 `STRINGS`, 카테고리 이름 `CATEGORY_LABEL`.
- `demo/src/demos/index.ts` — `DemoEntry`에 `titleEn`·`descriptionEn` 추가. 52개 항목의 영어 문구는 `README.en.md` 표에서 가져와 같은 이름을 쓴다.
- `demo/src/App.tsx` — 사이드바 브랜드 옆 토글 버튼(`English` / `한국어`), 카테고리·제목·설명·검색·사용 예시 블록 문구를 언어에 따라. 영어 화면의 데모 페이지에는 "데모 안은 한국어" 안내 한 줄. 데모 컴포넌트를 `<div lang="ko">`로 감싸 스크린 리더가 언어를 바꿔 읽게 함. 검색은 두 언어 문구를 모두 뒤진다.
- 테스트 5건: 초기 언어 결정 규칙, 카테고리·데모 항목 번역 누락 검사(새 스킬을 등록하면서 영어 문구를 빠뜨리면 실패), 두 언어 문구 키 일치.
- README 배지 tests 498.

## 3. 주의사항

- 스킬을 추가할 때 레지스트리에 `titleEn`·`descriptionEn`을 같이 넣어야 한다. 빠뜨리면 타입 오류와 테스트 실패로 잡힌다. AGENTS.md 절차 4단계에 반영 필요(이 브랜치에서는 README 절차만 있음 — 다음 스킬 추가 시 갱신).
- 데모 내부 문구는 한국어다. 전부 영어로 하려면 각 데모에 문구 사전을 넣는 별도 작업이 필요하다(52개 파일).
- 이 브랜치는 `feat/readme-en`(PR #25) 위에 쌓였다.
