## 1. 개요

사용자 요청은 두 가지다.

- README의 AI 슬롭 문장을 고친다.
- 이커머스 실사용 점검의 비교 시트처럼, AS-IS / TO-BE로 suta를 쓴 효과를 보인다.

## 2. 작업내용

- **비교 이미지** `docs/assets/as-is-to-be.jpg`
  - 2행 × 6열이다(1848×1432, JPEG 369KB).
    - 위 줄 AS-IS: suta 없이 만든 화면(이커머스 점검 1차의 일반 조건).
    - 아래 줄 TO-BE: suta 0.8로 만든 화면(3차 C).
    - 열 순서: 홈·상품 리스트·상품 상세·장바구니·마이·설정, 390px 캡처.
  - 그림 안 글자는 줄 머리 "AS-IS"·"TO-BE"뿐이다. 두 언어 README가 같은 그림을 쓴다.
- **사진 출처** `docs/assets/CREDITS.md`
  - 화면 속 음식 사진 12장의 작성자·라이선스·원본 주소를 적었다(위키미디어 커먼즈, CC0·CC BY·CC BY-SA).
  - CC BY-SA 사진이 섞여 있어 비교 이미지는 CC BY-SA 4.0을 따른다고 적었다.
- **README 구성**
  - 맨 위에 "AS-IS / TO-BE" 절을 두었다.
    - 요청문 원문을 인용했다.
    - 비교 이미지와 캡션을 넣었다.
    - 차이 표 7행을 넣었다: 색·아이콘·상품 카드·홈 검색·상세 하단 바·하단 탭·axe 111 → 0. 모두 연구 문서의 실측값이다.
  - 그 아래에 벤치마크·무엇을 막나·설치·쓰는 법·더 알아보기·라이선스를 두었다.
- **문장 손질 기준**
  - 줄표(—) 이음을 없앴다(각 7곳 → 0).
  - 굵은 머리말 글머리표("**편집 후 검사:**")를 평범한 문장으로 바꿨다.
  - 셋을 늘어놓는 도입("카드에 갇히고, 간격은 제각각이고, …")을 한 문장 정의로 바꿨다.
  - 숫자 없는 평가어를 뺐다: "결함이 크게 줄었습니다", "검증된 패턴", "잘 만든 사이트에 가까워졌습니다". 대신 숫자를 적었다(16px = 레퍼런스 중앙값, 61초 → 103초).
  - 뜻이 겹치는 표어 "AI 슬롭 없는 UI"를 뺐다.
  - "무엇을 막나" 표의 색 행을 지금 기준(강조색 하나 + 오류 빨강)에 맞췄다.
- **영어판**
  - 같은 구조와 같은 그림을 쓴다.
  - 남아 있던 "55 tested patterns"를 고쳤다.
- **배지**: 색을 무채색(`1b1e24`·`555555`)으로 바꿨다. 이전 초록 `34c759`는 이번에 패턴 기본값에서 뺀 iOS 초록이다. 숫자 형식은 검사 스크립트가 읽으므로 그대로 두었다.
