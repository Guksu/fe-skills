## 1. 개요

스킬 13종 시점에서 첫 화면·탐색이 빈약해 데모 사이트를 카탈로그로 재구성했다(사용자 선정 골 1). 브랜치 `feat/demo-catalog`(main에서 분기). 커밋 안 함.

## 2. 작업내용

- **레지스트리 확장** — DemoEntry에 `category`(5분류: 등장과 전환/로딩과 진행/피드백/내비게이션/제스처)·`emoji`·`usage`(대표 사용 예시 코드) 추가. 13종 전부 채움.
- **홈 카탈로그** — 카테고리 섹션별 카드 그리드(이모지+제목+설명), 검색(이름·설명·slug, 일치 수 표시), 스킬 수 자동 표기.
- **사이드바** — 카테고리 그룹 헤더 + 이모지, 스크롤 지원.
- **데모 페이지 "사용 예시" 블록** — usage 코드 표시 + 클립보드 복사 버튼(1.5초 후 라벨 복귀) + GitHub SKILL.md 링크.
- 게이트: 빌드·린트·테스트 72/72, 브라우저 확인(검색 필터·사용 예시 렌더).

## 3. 주의사항

- usage 스니펫은 SKILL.md 예시의 축약본 — SKILL.md를 고치면 registry의 usage도 함께 갱신할 것(이중 관리 지점).
- 커밋 안 됨 — 골 2·3과 함께 확인 후 커밋 예정.
