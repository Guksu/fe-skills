# 영어 README 추가

| 항목 | 내용 |

| 날짜 | 2026-09-18 |
| 작성 | 에이전트 |

## 1. 개요

레퍼런스 조사 5번 항목. README가 한국어뿐이라 skills.sh·GitHub에서 영어권 사용자가 내용을 알 수 없었다. Vue 래퍼는 사용자 결정으로 제외했다.

## 2. 작업내용

- `README.en.md` 신설(311줄) — 한국어판과 같은 절 순서·표·배지·링크. 절 앵커만 영어 제목 기준. 스킬 이름은 폴더명과 통용 용어를 살려 번역(예: 유리판 → Glassmorphism surface, 리스트 재배치 → List reorder (FLIP), 늘어나는 이미지 헤더 → Stretchy image header).
- `README.md` 제목 아래에 `English: README.en.md` 링크 한 줄, 영어판에는 `한국어: README.md`.
- `scripts/validateSkills.mjs` — 배지 검사가 `README.en.md`도 본다(있을 때). 두 문서의 스킬 수·테스트 수가 어긋나면 실패.
- `AGENTS.md` — 스킬 추가 절차에 "두 README 모두 갱신" 명시.

## 3. 주의사항

- 스킬을 추가할 때 표 행을 두 파일에 넣어야 한다. 배지는 검사가 잡지만 표 행 누락은 잡지 않는다.
- 이 브랜치는 `feat/motion-principles-audit`(PR #24) 위에 쌓였다.
- GitHub 저장소 topics(`agent-skills`, `claude-skills` 등)는 저장소 설정이라 이 세션에서 바꾸지 못했다. 사용자가 직접 추가하면 발견에 도움이 된다.
