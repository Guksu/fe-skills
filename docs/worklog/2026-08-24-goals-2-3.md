## 1. 개요

사용자 선정 순차 골 중 2(새 스킬 배치 5)·3(기존 스킬 심화)을 수행했다. 브랜치 `feat/demo-catalog`(골 1과 같은 브랜치). **커밋 안 함** — 골 1~3 전체가 육안 확인 대기.

## 2. 작업내용

**골 2 — 스킬 3종 (총 16종):**
- **press-feedback** — CSS-only. 비대칭 타이밍(누름 60ms 즉각/복귀 220ms 스프링), hover 게이트, reduced-motion은 밝기 피드백으로 대체. JS 없음(테스트 미대상).
- **toast-stack** — 코어 `createToastStack`(TDD 6건): 라이브 영역(role=status·aria-live) + 스택 밀어올리기(transform, offsetHeight 누적) + 자동 소멸 + maxVisible 초과 시 오래된 것 방출. React 훅 `useToastStack`.
- **zoom-lightbox** — 코어 `openZoom`(TDD 5건): 썸네일 복제 고스트를 화면 중앙 확대(공유 요소 전환 최소형), 백드롭·Esc·역방향 복귀·body 스크롤 잠금·타임아웃 폴백. React 래퍼 없음(코어 직접 호출로 충분 — 문서 명시).

**골 3 — 심화:**
- **bottom-sheet 스냅 포인트** — `snapOffsetsPx`(예: [0, 240]) 추가(TDD 5건): 반열림 시작·드래그로 스냅 간 이동(velocity로 nudge/fling 판정)·마지막 스냅 아래로는 닫힘. baseOffset은 인라인 transform에서 파싱. 초기 배치는 rAF 없이 동기 설정(스로틀 내성).
- **carousel 자동재생** — `createCarouselAutoplay`(TDD 5건): 호버·키보드 포커스 정지, 사용자 토글(WCAG 2.2.2 일시정지 버튼용), reduced-motion 미재생. `useCarousel({ autoplayMs })` + `autoplayOn`/`toggleAutoplay`.
- flip-list 문서의 "크기 FLIP" 항목은 zoom-lightbox 안내로 교체(중복 방지).

게이트: 빌드·린트·테스트 **93/93**, 구조 검증 OK, 브라우저 실동작(토스트 3연타 스택·줌 확대/Esc 복귀·스냅 반열림↔전체열림·자동재생 전환+일시정지 버튼, 콘솔 에러 0).

## 3. 주의사항

- **커밋 안 됨** — feat/demo-catalog에 골 1(카탈로그)+골 2+골 3 누적.
- 자동화 left_click_drag는 드래그 끝에 클릭 이벤트를 도착 지점 요소에 쏜다 — 시트 위로 드래그 시 백드롭 클릭으로 오판된 사례 있음(제품 동작 아님). 제스처 검증은 JS 포인터 시퀀스 기준.
- 토스트 스택 위치를 CSS로 옮길 수 있으나 `.toast-item`의 transform은 코어 소유(문서 명시).
