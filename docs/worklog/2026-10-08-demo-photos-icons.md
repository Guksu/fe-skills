## 1. 개요

진입 스킬의 "글자·색·면" 금지선은 이모지를 아이콘이나 상품 사진 대신 쓰지 말라고 한다. 그런데 데모 사이트는 음식 썸네일(🍜 🥟 🧊 🌶️)과 행동 아이콘(❤️ 📞 🔗 🛒)을 여전히 이모지로 그렸다. main(0.8.0)은 `emoji-icon` 규칙을 더하면서 데모 33개에 파일 단위 무시 주석(`layout-audit-ignore-file: emoji-icon`)을 달아 두었다. 사용자 요청은 이를 실제 음식 사진이나 선 아이콘으로 바꾸고, 그 무시 주석을 지우는 것이었다.

처음 작업은 0.7.0(c0f6456) 위에서 했다. 그 사이 main에 규칙·아이콘 한 벌·무시 주석이 들어와 PR #39가 충돌했다. 저장소 훅이 에이전트의 `git merge`를 막으므로, 사용자 결정에 따라 최신 main(77b32e1)에서 새 브랜치 `feat/demo-photos-icons`를 만들어 같은 변경을 다시 적용했다. 이때 데모 전용으로 만들었던 아이콘은 main의 아이콘 한 벌로 바꿨다.

## 2. 작업내용

- **음식 사진** — `demo/public/photos/*.webp` 18장 + `demo/src/shared/dishes.ts`(단일 출처)
  - 출처는 위키미디어 공용(Wikimedia Commons)이다. 라이선스는 CC0 8장, CC BY(2.0·2.0 KR·4.0) 10장이다. 동일조건(BY-SA)·비영리(NC)는 쓰지 않았다.
  - 저자·라이선스·원본 링크는 Commons API의 메타데이터에서 그대로 옮겼다.
  - 모두 4:3으로 잘라 줄이고 WebP로 바꿨다. 한 장에 40KB 이하, 합계 596KB다.
    - 질감이 많은 감자전·냉모밀은 640×480으로 줄여 화질을 지켰다.
  - 사용자 승인 후 내려받았다.
- **사진·아이콘 출처 페이지** — `#/credits`
  - 사이드바 아래에 GitHub 옆으로 "사진·아이콘 출처" 링크를 달았다.
  - CC BY가 요구하는 것을 모두 적었다: 저작자, 라이선스 링크, 원본 링크, 변경 사실(잘라 줄임·WebP 변환).
  - 아이콘은 suta 아이콘 한 벌(Lucide v0.469.0, ISC)이라고 적었다. 한국어·영어 문구 모두 `i18n.ts`에 있다.
- **`DishPhoto`** — `demo/src/shared/DishPhoto.tsx`
  - `img`에 실제 크기(width·height)·`loading="lazy"`·`draggable={false}`를 준다.
  - 크기·비율은 틀(데모 클래스)이 정하고, 사진은 `object-fit: cover`로 잘라 채운다.
  - 기본 스타일(`styles.css`의 `.dish-photo`)은 `:where()`로 우선순위를 0으로 두었다.
    - 이유: `main.tsx`가 App(데모 CSS)을 셸 CSS보다 먼저 불러온다. 그래서 그냥 클래스로 두면 데모가 같은 우선순위로 덮어쓴 값을 셸이 다시 덮는다.
- **아이콘** — main의 `@skills/layout-principles/assets/Icon`(아이콘 한 벌)을 그대로 쓴다
  - 한 벌에 없던 5개를 같은 출처(Lucide v0.469.0)의 원본 경로 그대로 더했다(40 → 45개).
    - 더한 것: `phone`·`eye-off`·`play`·`pause`·`bowl`(Lucide soup — 가게 로고·주문하기).
    - `PATTERN.md` 파일 표와 `tone.md`의 개수를 45개로 고쳤다.
  - 링크 복사는 기존 `share`, 스크롤 안내 화살표는 `chevron-down`으로 대신했다.
  - 처음에 만든 데모 전용 `demo/src/shared/Icon.tsx`(Feather 경로)는 지웠다. 한 벌을 섞지 않기 위해서다.
  - 즐겨찾기 표시는 `Icon`의 `label`로 이름을 준다(`role="img"`).
- **데모별 교체** — 무시 주석 33개를 모두 지웠다
  - 목록 행 썸네일은 목록마다 한 크기의 정사각으로 맞췄다. 크기는 32·40·48·56·72px이다.
    - 해당 데모: 순서 바꾸기·가장자리 뒤로가기·FLIP·화면 전환·수량·가격 슬라이더·검색 제안·세그먼트·테마·유리 GNB.
  - 사진이 주인공인 데모는 사진 자체를 쓴다.
    - 라이트박스: 사진 단추만 커지고, 이름은 밖에 둔다.
    - 그 밖: 핀치 확대·끌어서 닫기 뷰어·늘어나는 헤더·카드 확장·카트 플라이·캐러셀·좋아요·누름 피드백·길게 누르기·유리판(카드와 유리 뒤 타일 24장).
  - 스토리는 가로 사진을 세로 화면 가운데에 폭 가득 두고, 글은 사진 아래에 둔다(스토리 앱의 관례).
    - 장면 사진에 맞춰 두 장면의 문구를 바꿨다: 오전 9시 "반죽을 밀어 썹니다", 밤 9시 "마지막 손님의 바지락칼국수".
  - 행동 아이콘
    - 바텀시트 메뉴, 길게 누르기 메뉴 항목, 매장·주문 행, 장바구니 단추, 캐러셀 재생·일시정지, 스크롤 안내, 스프링 공·하트, 레이아웃 원칙 데모의 찜(♡ 글자) → 선 아이콘.
  - 가게 계정 프로필(좋아요·핀치)은 무채색 원 + 그릇 로고로 바꿨다. 지갑 카드 머리의 발급처 자리도 같은 로고다.
  - 사람 프로필(스켈레톤)은 무채색 원 + 사람 아이콘으로 바꿨다.
  - 토스트·모달·폼·휠 피커·툴팁 문구 끝의 이모지는 지웠다. 문장 하나로 결과를 알린다.
  - Commons에 쓸 만한 열무국수 사진이 없었다. 그래서 길게 누르기 데모의 열무국수를 바지락칼국수로 바꿨다.
  - 레이아웃 원칙 데모의 가짜 사진(이모지를 그려 넣은 SVG)을 실제 사진(잔치국수·들깨칼국수)으로 바꿨다.
  - 끌어서 닫기 뷰어의 이모지 SVG 생성 함수를 지웠다.
  - 사진 자리 톤을 위해 두었던 무시 주석 2개(card-expand의 hue-count·tinted-surface)는 필요가 없어져 지웠다.
- **셸**
  - 레지스트리의 `emoji` 필드(56개, bottom-nav 포함)와 사이드바·데모 제목·홈 카드의 이모지를 지웠다. 목록은 글자만 남는다.
- **설치되는 패턴(0.8.1)**
  - `QuantityStepper`의 삭제 표시 🗑 → 휴지통 선 아이콘. 경로는 아이콘 한 벌의 `trash`와 같다(패턴이 혼자 완결되도록 인라인 SVG).
  - `FileDropZone`의 📄는 main이 이미 선 아이콘으로 바꿔 두어 그대로 받았다.
  - PATTERN.md 예시 코드의 이모지를 바꿨다. 데모의 사용 예시 문자열도 같이 고쳤다.
    - cart-fly·tooltip: 🛒 → `<Icon name="cart" />`(`import { Icon } from './Icon'`, bottom-nav 문서와 같은 형식).
    - glass-nav: "🍜 국수집" → "국수집".
    - cart-fly·card-expand: 사진 자리 → `<img>`.
  - 버전을 매니페스트 3개에서 함께 0.8.1로 올렸다.
- **테스트 픽스처**
  - `cartFlyCore`·`cardExpandCore` 테스트에서 이모지 글자 대신 `<img>`를 복제·전환 대상으로 쓴다.

  - 새 사진 칸 때문에 반경 종류가 4종이 되는 파일이 2개 생겼다.

## 3. 주의사항

- **PR #39는 닫는다.** 0.7.0 위에서 만든 첫 PR이다. 같은 변경을 최신 main 위에 다시 적용한 새 PR이 대신한다. 브랜치 `feat/infallible-heisenberg-08eec1`은 지우지 않았다(브랜치 삭제는 사용자 몫).
- **Stop 훅(검증자 게이트)의 Node 버전**
  - 게이트는 `/usr/local/bin/node`(v22.12.0)로 돌아 `scripts/lib/*.ts`를 읽지 못한다. 그래서 skills-structure·skills-selection이 실패로 나온다.
  - 이번 변경과 무관하게 main에서도 같다. Node 22.18 이상이 필요하다.
- **사진을 바꾸거나 더할 때**
  - 파일을 바꾸면 `demo/src/shared/dishes.ts`의 credit(저자·라이선스·원본)과 크기를 함께 고친다. 출처 페이지가 이 목록을 그대로 보여 준다.
  - 새 사진도 CC0·CC BY만 쓰고, 한 장 40KB 이하를 지킨다.
- **아이콘을 더할 때**
  - `icons.ts`의 안내대로 같은 출처(Lucide)의 원본 경로를 같은 형식으로 더한다. 다른 아이콘 세트와 섞지 않는다.
- **사진이 맞지 않는 메뉴**
  - 냉모밀은 일본식 자루소바 사진이다. 한국식 냉모밀 사진이 Commons에 없다.
  - 들깨칼국수는 칡칼국수 사진이다(같은 들깨 국물).
  - 원본이 작은 사진은 크게 띄우면 흐릴 수 있다: 들깨칼국수 600px, 반죽 708px, 육수 재료 512px.
- **끌어서 닫기 뷰어**
  - 썸네일은 정사각, 크게 보기는 4:3이다. 닫힐 때 사진은 썸네일 폭에 맞춘 4:3으로 돌아간 뒤 사라진다.
  - 늘어나지는 않는다(균일 배율).
- 데모 미리보기용 `.claude/launch.json`은 확인 뒤 지웠다. 직접 확인은 `npm run dev`로 한다.
