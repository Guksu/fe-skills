## 1. 개요

suta의 README에서 반복되는 홍보 문구와 비유를 덜어내고, 실제 기능과 실험 결과를 중심으로 설명을 정리했다. 한국어와 영어 문서에 같은 수정 방향을 적용했다.

## 2. 작업내용

- 소개를 레이아웃·색·모션 기준과 UI 패턴 코드에 대한 설명으로 바꾸고, 중앙 정렬과 중복 배지를 제거했다.
- 설치 바로가기를 추가하고, 비교 표의 어색한 표현을 검색창·헤더·배지 등 일반적인 UI 용어로 바꿨다.
- 반복되는 대비표와 수타면 비유를 덜고, 스킬·패턴 코드·편집 후 검사의 역할을 설명했다.
- 실험 수치와 비교 이미지는 유지했다. 장식 수를 품질 점수로 읽게 하는 문구를 제거하고, 모델 평가와 정적 검사의 범위를 명확히 했다.
- 실험 횟수를 본문의 실제 조건에 맞춰 1~4회로 정정했다.
- Node 22.23.2에서 빌드·린트·테스트(89개 파일, 743개 케이스)와 `npm run validate`를 통과했다. 선택 평가는 461/461, 통합 검사는 오류 0개·경고 22개였다.
- 두 README의 로컬 링크를 각각 24개 확인했고, 설치 명령과 비교 이미지 경로가 기존과 같음을 확인했다. `git diff --check`도 통과했다.

## 3. 주의사항

비교 수치는 기존 연구 결과이며, 이번 작업에서 실험을 다시 실행하지 않았다. 설치 명령, 스킬과 패턴 코드, 검사 설정은 변경하지 않았다. 빌드에는 500kB를 넘는 번들에 대한 경고가 있으며, README 테스트 배지 633은 검사 스크립트가 세는 정적 테스트 선언 수로 실제 실행 케이스 743과 다르다.
