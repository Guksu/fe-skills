## 1. 개요

사용자가 "증권 플랫폼의 웹 사이트를 만들어서 벤치마크 해보자"고 했다. 정한 것은 아래와 같다.

- 범위: 측정 → 개선 → 재측정
- 화면: 7개 + GNB
- 폭: 데스크톱 중심, 모바일 확인
- 실행: 일반 2번·suta 2번, 개선 뒤 suta 2번

빈 Vite 프로젝트에 같은 요청을 `claude -p`로 주고 비교했다. 그다음 증권 웹 10곳과 앱 화면 55장을 레퍼런스로 삼아 suta를 고치고, 다시 돌렸다.

- **실험 자료**: 실험 폴더는 저장소 밖 `/home/user/suta-bench/securities/`다. 산출물·캡처·대화 기록·레퍼런스 원자료가 들어 있다. 저장소에는 넣지 않았다. 레퍼런스 사이트 이름은 그 폴더의 `sites-key.md`·`services-key.md`에만 있다.

  - 실행 8번은 0.54~2.15달러였다.
