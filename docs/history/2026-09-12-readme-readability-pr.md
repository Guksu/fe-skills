# README 가독성 개선

| 항목 | 내용 |
|------|------|
| 날짜 | 2026-09-12 |
| 작성 | 프로젝트 문서 작업 |
| 관련 경로 | `README.md` |
| 브랜치 | `docs/readme-readability-pr` |

## 1. 개요

README의 소개와 스킬 설명을 간결하게 정리하고, 설치와 사용 예시를 앞쪽에 배치했다. 처음 방문한 독자가 플러그인의 용도와 사용 방법을 빠르게 파악하도록 표와 문서 흐름을 개선했다.

## 2. 작업내용

- `README.md`: 플러그인 비교표와 핵심 원칙으로 소개를 정리했다.
- UI 스킬 표의 중복 영문 이름 열을 제거하고 주요 동작 설명을 간결하게 다듬었다. 최신 main의 스킬 41개와 문서·데모 링크를 유지했다.
- 설계 스킬의 진행 방식과 화면 유형별 가이드를 정리했다.
- 데모 실행과 검증 명령을 구분하고, 기여 절차와 관련 문서를 정리했다.

- 최신 `main`에 추가된 UI 스킬 4종과 배지 숫자를 유지하도록 반영했다.

검증 결과:

| 검증 | 결과 |
|------|------|
| `npm run build` | 통과 |
| `npm run lint` | 통과 |
| `npm test` | 최신 main 기준 57개 파일, 371개 테스트 통과 |
| `node scripts/validateSkills.mjs` | 통과 |
| README 스킬 목록·상대 링크 검사 | 최신 main의 UI 스킬 41개 유지 및 상대 링크 대상 존재 확인 |
| `git diff --check` | 통과 |

임시 링크 검사에서 코드 블록까지 포함하는 정규식 때문에 최초 검사가 실패했다. Markdown 링크만 추출하도록 검사식을 수정한 후 스킬 41종과 상대 링크 검사가 통과했다.

## 3. 주의사항

문서 변경이며 실행 코드는 수정하지 않았다. PR 대상 브랜치는 저장소에 `dev`가 없어 기본 브랜치인 `main`을 사용한다.
