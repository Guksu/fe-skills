# 글자·색·면 — 레퍼런스 재분석

| 항목 | 내용 |
|------|------|
| 날짜 | 2026-10-07 |
| 방법 | ① 앞서 기록한 국내 앱 화면 1,104장(31곳)의 기록과 관찰 메모를 글자·색·면 기준으로 다시 집계했다. ② 디자인 피드백 사례 중 색 45건·타이포 47건·대시보드 14건·랜딩 38건을 다시 읽었다. ③ 웹사이트 19곳(앞 조사와 같은 목록)의 글자색·바탕·면·자간·행간을 새로 쟀다. ④ 같은 지표로 벤치마크 1차 산출물 32개를 쟀다 |
| 상태 | 반영 완료. `layout-principles` 토큰에 색 역할을 더하고, 진입 스킬에 "글자·색·면" 금지선과 화면 유형별 세부 관례를 더했다. 출처(사이트·서비스 이름)와 화면 이미지는 남기지 않는다 |

## 1. 한눈에

벤치마크 1차에서 suta 화면은 결함 지표가 거의 0이었다. 그런데도 판정은 일반 쪽이 우세했고, 사람 눈에도 "AI가 만든 것 같다"는 인상이 남았다. 장식을 걷어 낸 자리에 아무것도 채우지 않았기 때문이다. 레퍼런스와 같은 지표로 재 보니 차이는 세 군데였다.

- **본문이 보조 크기다.**
  - 화면에서 가장 많은 글자의 크기가 suta 16개 모두 14px이다. 잘 만든 사이트는 16px(중앙값)이다.
  - 보조 크기(14px)를 설명·본문에까지 써서 화면 전체가 흐려졌다.
  - 작은 글자가 많은 것 자체는 문제가 아니었다. 잘 만든 모바일 사이트도 15px 미만 글자가 중앙값 59%다(메뉴·메타가 많아서). 문제는 본문 자리다.
- **면이 하나뿐이다.**
  - suta 화면 16개 중 10개가 흰 바탕 하나에 선만 썼다. 회색 면은 중앙값 0개다.
  - 잘 만든 사이트는 회색 면을 1~2개 쓰고, 넓은 면에 테두리·그림자를 쓰지 않는다(중앙값 100%).
  - 잘 만든 앱은 구역 사이에 8px 옅은 띠를 깔고(25곳), 입력칸·보조 버튼·안내 상자를 회색으로 채운다(28곳). 카드를 쓰는 화면에서도 카드의 71%는 테두리·그림자 없이 바탕 톤 차이만 쓴다.
- **강조색이 기본값이고, 한 곳에만 있다.**
  - suta 화면 16개 중 9개가 프레임워크 기본 파랑(`#2563eb` 계열)이었다.
  - 잘 만든 앱은 채운 버튼 색이 서비스마다 다르다. "안전한 기본색"이 없다.
  - 잘 만든 앱은 같은 강조색을 선택 상태(55번)·탭(22번)·밑줄(18번)·링크(10번)에 이어 쓴다. suta 1차는 강조색을 주 버튼에만 써서, 글자 중 강조색인 비율이 중앙값 0%였다.
  - 웹 레퍼런스도 강조색 글자는 적다(중앙값 0.5~1.0%, 위 사분위 6.4~6.8%). 흑백 위주의 브랜드 사이트가 많아서다. 그래서 "얼마나 많이"가 아니라 "어디에 이어 쓰나"를 기준으로 삼았다.

자간은 차이가 없었다. 레퍼런스도 자간을 거의 손대지 않는다(중앙값 0). 그래서 자간 규칙은 만들지 않았다.

## 2. 방법과 한계

### 자료

- **앱 화면 기록(재집계)**
  - 앞선 조사(`2026-10-07-screen-conventions.md`)의 화면별 기록 1,116장(집계 1,104장)이다.
  - 에이전트가 화면마다 적은 관찰 메모 3,250문장도 함께 썼다.
  - 이번에는 색 이름·면(띠·채움·카드)·글자 크기를 적은 문장을 정규식으로 뽑아 셌다.
  - 이미지 원본은 앞 조사에서 지웠다. 새로 받지 않았다.
- **디자인 피드백 사례(재독)**
  - 레이아웃 원칙 조사(`2026-10-06-layout-principles.md`)의 462편 분석 기록이다.
  - 태그가 색·타이포인 사례와, 화면이 대시보드·랜딩인 사례를 다시 읽었다.
- **웹사이트(새로 측정)**
  - 앞 조사와 같은 목록이다. 레퍼런스 사이트의 웹 목록(좋아요순) 23곳 중 robots.txt가 허용한 19곳이다.
  - 데스크톱 1440px·모바일 390px에서 보이는 글자의 색·크기·굵기·자간·행간을 계산된 스타일로 쟀다. 면(바탕색이 칠해진 요소)의 색·넓이·테두리·그림자도 쟀다.
  - 글자가 10개 미만으로 잡힌 사이트는 뺐다. 그래서 데스크톱·모바일 각 14곳이다.
  - 글자 수는 공백을 뺀 글자로 센다. 처음 측정에서는 들여쓰기 공백만 있는 요소도 글자로 세서 작은 글자 비율이 낮게 나왔다. 고쳐서 다시 쟀고, 이 문서의 수치는 모두 고친 값이다. 조상이 투명하거나 숨긴 글자는 뺀다(벤치마크 측정과 같은 기준).
  - 페이지 사이 3초 이상 쉬었다. 원자료는 세션 임시 폴더에만 두고 분석 뒤 지웠다.
- **벤치마크 1차 산출물** — 같은 측정 스크립트를 일반·suta 화면 32개에 돌렸다.

### 한계

- **앱 수치는 문장에서 뽑았다.** 크기는 에이전트가 이미지를 보고 적은 pt 값이라 ±5% 안팎의 오차가 있다. 15·16·17처럼 붙은 값은 서로 구별하지 않았다.
- **색은 이름으로만 안다.** 앱 기록에는 색 값이 없고 "파랑 채움" 같은 이름만 있다.
- **웹 레퍼런스는 브랜드·포트폴리오 사이트가 많다.** 해외 사이트가 대부분이고, 한국어 사이트는 4곳이다. 앱 화면과는 성격이 달라서, 면·강조색은 앱 기록을 먼저 보고 웹 측정을 보조로 썼다.
- **"강조색 글자 비율"은 채도로 판정했다.** 채도 0.35 이상·밝기 0.15~0.85인 색을 강조색으로 셌다. 갈색·남색처럼 채도가 낮은 브랜드색은 빠질 수 있다.

## 3. 면 — 흰 면과 옅은 바탕, 두 단계

### 앱(1,104장)

| 무엇 | 측정 |
|---|---|
| 묶는 수단(순위 무관) | 간격 79% · 선 41% · 옅은 바탕 35% · 카드 25% |
| 카드를 쓴 화면 369장의 카드 | 테두리·그림자 없음 71% · 테두리만 19% · 그림자만 9% · 둘 다 1% |
| 서비스 평균(카드 3장 이상인 29곳) | 테두리·그림자 없는 카드 67% |
| 구역 사이 옅은 띠 | 25곳·98번. 높이 8/9/18pt, 가장 흔한 값 8 |
| 흰 바탕 위 회색 채움 상자(입력칸·보조 버튼·안내 상자·타일) | 28곳·127번 |
| 회색 바탕 위 흰 묶음(설정·목록) | 11곳·18번 |
| 얇은 선으로 행 나눔 | 27곳·199번 |

### 웹(19곳)

| 무엇 | 데스크톱 | 모바일 |
|---|---|---|
| 페이지 바탕이 흰색 | 14곳 중 11곳 | 14곳 중 11곳 |
| 바탕 말고 넓은 회색 면의 종류 | 1/1/2 | 1/2/2 |
| 넓은 면 중 테두리·그림자 없는 비율 | 100/100/100% | 88/100/100% |

### 디자인 피드백

- 회색 면은 "여기부터 다른 구역"을 알릴 때만 쓴다. 카드 바탕·보조 버튼·태그·안내 상자에 같은 회색을 모두 깔면 칙칙해진다.
- 면 안에 면(카드 안 카드, 회색 위 회색)을 겹치지 않는다.
- 얇은 테두리로 나눈 작은 상자들은 테두리를 없애고 옅은 면 하나로 합친다. 선 여러 개보다 면 하나가 화면에 무게를 준다.

### 결론

면은 두 단계다. 흰 면과 옅은 회색 바탕이다. 회색은 셋 중 하나로 쓴다. 구역 사이 8px 띠, 흰 바탕 위 회색 채움 상자, 회색 바탕 위 흰 묶음이다. 카드는 테두리·그림자 대신 이 톤 차이로 나눈다.

## 4. 색 — 강조색 하나를 정해 이어 쓴다

### 앱

| 무엇 | 측정 |
|---|---|
| 채운 주 버튼의 색(관찰 메모에 색을 적은 서비스) | 파랑 4곳 · 검정 3곳 · 주황 2 · 빨강 2 · 초록 2 · 노랑 2 · 보라·민트·분홍·남색 각 1 |
| "강조색"과 함께 적힌 요소 | 버튼 103 · 글자 81 · 선택 상태 55 · 아이콘 40 · 점 23 · 탭 22 · 밑줄 18 · 체크 13 · 칩 12 · 숫자 12 · 링크 10 |
| 선택 표시 | 탭은 굵은 글자 + 밑줄(16곳). 칩·선택지는 짙은 채움(8곳)·강조색 테두리나 글자(10곳)·강조색 채움(6곳) |
| 상태 색 | 할인을 적은 21번 중 빨강 13번. 오류를 적은 45번 중 빨강 23번 |
| 소셜 로그인 버튼 | 5곳 중 4곳이 서비스 고유 색과 로고(노랑·검정 등), 1곳은 중립 회색으로 통일 |
| 라디오·스위치 | 선택된 것만 강조색(링 + 점, 켜진 트랙). 나머지는 옅은 회색 윤곽선 |

### 웹

| 무엇 | 데스크톱 | 모바일 |
|---|---|---|
| 채도 높은 색의 종류(글자·면) | 0/1/3 | 0/1/2 |
| 글자 중 강조색인 비율 | 0/1.0/6.8% | 0/0.5/6.4% |
| 글자 색 종류(글자 수 2% 이상) | 3/3/4 | 3/4/5 |
| 그중 무채색 단계 | 2/3/4 | 2/3/4 |
| 가장 많은 글자 색이 순수 검정(#000) | 14곳 중 6곳 | 14곳 중 5곳 |

### 디자인 피드백

- 색은 역할로 먼저 정한다. 주 색 1개, 회색 단계, 상태 색이다. 새 요소는 그 안에서만 고른다(대시보드 사례).
- 색의 세기를 세 단계로 나눈다.
  - 강: 확정 버튼처럼 진한 면이다.
  - 중: 선택된 날짜·항목이다. 흰 칸 + 진한 글씨, 또는 옅은 색 바탕 + 가는 테두리다.
  - 약: 옅은 색 띠다.
  - 진한 면이 여러 곳이면 시선이 흩어진다.
- 보조 글 회색은 감으로 고르지 않는다. 명암비 4.5:1을 재 둔 색 목록에서만 꺼낸다. 회색 단계는 한두 개다.
- 색을 연하게 하면 굵기를 올린다. 둘 다 약하게 하지 않는다.
- 항상 떠 있는 하단 탭·바에는 채도 높은 색을 쓰지 않는다.
- 차트는 한 색의 농도 차이로 그리고, 가장 중요한 막대 하나만 진하게 한다.

### 결론

- 강조색은 하나다. 브랜드색이 있으면 그것을 쓴다. 없으면 서비스 성격에서 고른다. 레퍼런스에 "안전한 기본색"은 없다.
- 채운 면은 주 버튼 한 곳이다. 같은 색을 선택 상태·밑줄·링크·핵심 숫자에 이어 쓴다.
- 글자 색은 주·보조·옅은 세 단계다.
- 상태 색은 빨강(오류·할인)·초록(완료)·주황(주의)이다.
- 외부 서비스 버튼은 그 서비스의 색을 쓴다.

## 5. 글자 — 본문 크기, 작은 글자의 몫, 행간

### 크기

| 무엇 | 레퍼런스 | 벤치마크 1차 suta | 벤치마크 1차 일반 |
|---|---|---|---|
| 가장 많은 글자의 크기 | 웹 16(모바일 13/16/16, 데스크톱 14/16/16) · 앱 보통 굵기 13/15/19 | 14/14/14 | 12/13/14 |
| 15px 미만 글자의 비율 | 모바일 14/59/82% · 데스크톱 1/26/61% | 47/65/73% | 58/62/70% |
| 가장 큰 글자 ÷ 본문 | 모바일 웹 1.7/2/2.4 | 1.7/2/2.5 | 1.5/1.9/2.5 |

- 앱 관찰 메모의 글자 크기 300건(28곳)에서, 보통 굵기는 13/15/19pt, 굵은 글자는 17/20/26pt였다.
- 가장 흔한 값은 17·13·15·16·12·14·22 순이다.
- 위계의 폭(가장 큰 글자 ÷ 본문)은 suta도 레퍼런스 범위 안이었다. 작은 글자 비율도 레퍼런스 모바일 범위 안이다. 문제는 본문 자리를 보조 크기가 차지한 것이다.

### 행간·자간·굵기

| 무엇 | 데스크톱 | 모바일 | suta 1차 |
|---|---|---|---|
| 본문 행간(13~18px 글자) | 1.29/1.41/1.5 | 1.33/1.5/1.5 | 1.6(전부) |
| 큰 글자 행간(24px 이상) | 1.0/1.2/1.25 | 1.0/1.2/1.3 | 1.3 |
| 자간(본문·큰 글자) | 0 | 0 | 0 |
| 굵기 종류 | 2 | 2/2/3 | 3 |

한국어 사이트 4곳의 본문 행간은 1.12~1.75로 넓게 흩어졌고, 자간은 모두 0이었다.

### 결론

- 화면에서 가장 많은 글자는 본문 크기 16px이다(앱 화면은 15~16).
- 설명·본문에 보조 크기(14px 이하)를 쓰지 않는다. 15px 미만은 메타·시각·라벨·법적 고지에 쓴다.
- 본문 행간은 1.5다. 1.6은 레퍼런스 범위 밖이다.
- 큰 제목 행간은 1.25~1.3이다. 한글 두 줄 제목은 1.2보다 조금 넉넉히 둔다.
- 자간은 건드리지 않는다.

## 6. 화면 유형별 세부 관례(앱 관찰 메모)

뼈대는 앞 조사에 있다. 이번에는 판정에서 지적된 부분(묶음, 버튼, 행 구성)을 메모에서 다시 찾았다.

| 유형 | 관찰 |
|---|---|
| 로그인 | 소셜 버튼은 서비스 고유 색 + 왼쪽 로고 + 가운데 글자, 같은 폭·높이(47~60pt), 간격 8~17pt. 이메일 로그인을 글자 링크로 낮추는 곳도 있다. 보조 이동(회원가입·비밀번호 찾기)은 글자 링크(밑줄 또는 강조색 글자) |
| 설정 | 두 방식이 흔하다. ① 흰 바탕 + 옅은 띠(40pt 안팎)에 작은 회색 구역 라벨 + 흰 행(47pt, 왼쪽 20pt 들인 선). ② 회색 바탕 + 흰 둥근 묶음(모서리 15~17pt, 좌우 16pt, 테두리·그림자 없음), 구역 라벨은 묶음 밖 위(라벨~묶음 8pt, 묶음~다음 라벨 20~28pt). 오른쪽 끝 요소가 동작을 알린다(꺾쇠 = 이동, 값 + 꺾쇠 = 선택, 스위치 = 켜고 끔). 로그아웃은 일반 행과 같은 모양, 탈퇴도 채운 빨강 버튼을 쓰지 않는다 |
| 장바구니·주문서 | 구역(상품·쿠폰·금액)을 8~10pt 회색 띠로 나눈다. 맨 위 "전체 선택" 줄의 오른쪽 끝에 "선택 삭제" 글자 링크. 상품 행은 정가(취소선) 아래 굵은 판매가를 오른쪽 끝에 맞춘다. 수량 스테퍼는 썸네일 아래나 가격과 한 줄. 금액 요약은 라벨 왼쪽·금액 오른쪽, 합계 줄만 굵게 키우고 할인은 강조색이나 빨강. 하단 고정 바에 최종 금액을 넣는다 |
| 상세·옵션 | 옵션 그룹은 굵은 제목 + 라디오 행, 그룹 사이 얇은 선, 큰 구역 사이 8pt 띠. 라디오는 선택된 것만 강조색 링 + 점. 가격은 왼쪽 굵게, 수량 스테퍼는 같은 줄 오른쪽 끝 |
| 목록·검색 결과 | 같은 규격 행 반복, 행 사이 선 또는 간격. 정렬은 목록 바로 위 오른쪽 끝의 회색 작은 글자 + 화살표. 선택된 필터 칩은 짙은 채움이나 강조색 테두리 |

## 7. 대시보드·랜딩(디자인 피드백)

앱 기록에는 없는 유형이라 피드백 사례(대시보드 14건, 랜딩 38건)로 정리했다.

- **대시보드**
  - 틀은 "왼쪽 메뉴 | 오른쪽 내용" 두 덩어리다.
  - 메뉴는 카드로 띄우지 않고 페이지 바탕과 같은 톤으로 가장자리에 붙인다. 흰 카드는 지표·차트 같은 데이터 묶음에만 쓴다. 제목·필터 줄은 카드로 싸지 않는다.
  - 지표 카드: 숫자는 이름의 2~3배다. 증감은 숫자 아래 작은 한 줄이고, 색 알약은 쓰지 않는다.
  - 왼쪽 메뉴의 글자는 세 단계다. 그룹 이름은 가장 옅고 작게, 1단계는 진하게, 하위는 한 단계 작고 옅게 둔다.
  - 차트는 한 색의 농도 차이로 그린다. 강조할 막대 하나만 진하게, 값은 막대 옆에 적는다.
- **랜딩**
  - 첫 화면의 메시지는 하나다. 제목은 생각보다 크게 잡는다(데스크톱 48~64px).
  - 섹션 제목은 대제목보다 한 단계 확실히 낮춘다.
  - 같은 크기 상자만 반복하지 않는다. 큰 모듈 하나와 작은 모듈 여럿으로 리듬을 만든다.
  - 기능 4개 안팎은 "번호 + 제목" 한 열과 얇은 선으로도 충분하다.
  - 제목 위 작은 알약 라벨이 메뉴를 반복하면 뺀다.
  - 얇은 테두리 상자 여러 개보다 옅은 면 하나가 무게를 준다.

## 8. 벤치마크 판정과의 대응

1차 판정에서 suta가 진 이유와 이번 근거를 맞대면 다음과 같다.

| 판정 이유 | 근거 | 반영 |
|---|---|---|
| 설정: 평평한 목록, 구획이 약함 | 3·6절 — 옅은 띠나 회색 바탕 위 흰 묶음 | 면 두 단계, 설정 관례 두 방식 |
| 로그인: 소셜 버튼 단색, 링크가 회색이라 링크로 안 보임 | 4·6절 — 고유 색, 글자 링크는 밑줄이나 강조색 | 외부 서비스 버튼 색, 링크 표시 |
| 장바구니: 가격이 떠 있음, 전체 선택 없음 | 6절 — 전체 선택 줄, 가격·스테퍼 한 줄 | 장바구니 관례 |
| 검색 결과: 상태 구분이 약함, 선택된 칩이 없음 | 4·6절 — 상태 색 글자, 선택 칩 표시 | 상태 색, 선택 표시 |
| 대시보드: 내비게이션 없음, 밋밋 | 7절 — 왼쪽 메뉴 + 흰 데이터 카드 | 대시보드 관례 |
| 데스크톱: 흰 바탕에 좁은 열이 덩그러니 | (레퍼런스에 직접 근거 없음 — 판정 이유) | 모바일 기준 화면은 넓은 창에서 옅은 바탕 위 흰 열로 |

## 9. 반영 결정

## 10. 반영 뒤 확인

벤치마크 2차(`docs/benchmark.md`)에서 suta 쪽의 가장 많은 글자는 16px, 회색 면은 1종, 파랑·남색·보라 주 버튼은 0/16이 됐다. 블라인드 판정은 기본 판정 모델 11 : 21(1차 7 : 25), 다른 판정 모델 19 : 13(1차 14 : 18)이다. 남은 감점은 사진 자리표시(회색 칸 + 선 아이콘이 와이어프레임처럼 보임)와 화면별 마감 결함이다.
